# QUALITY IMPROVEMENT SUGGESTIONS
# ============================================================================

# 1. SAMPLER & STEPS OPTIMIZATION
#    - Best samplers for quality (in order):
#      * DPM++ 2M SDE Karras (50-80 steps) - Best quality, slower
#      * DPM++ SDE Karras (25-40 steps) - Great balance
#      * Euler a (20-30 steps) - Fast, good for testing
#      * DPM++ 2M (20-30 steps) - Fast alternative
#    - More steps = better quality but diminishing returns after 50-80
#    - For Hires.Fix: Use same sampler or DPM++ 2M SDE (20-30 steps)

# 2. CFG SCALE TUNING
#    - Default: 7.0 (good starting point)
#    - Lower (4-6): More creative, less prompt adherence
#    - Higher (8-12): Stronger prompt adherence, may look over-processed
#    - Sweet spot: 6.5-8.0 for most photorealistic work
#    - Very high (15+): Can introduce artifacts

# 3. RESOLUTION & ASPECT RATIO
#    - Use native model resolutions (512x512, 768x768, 1024x1024)
#    - Avoid odd aspect ratios unless model specifically supports them
#    - For portraits: 768x1024 or 896x896 (Realistic Vision V6.0)
#    - For landscapes: 1024x768 or 1152x640
#    - Higher resolution ≠ always better (can cause artifacts)
#    - Use Hires.Fix instead of generating at high resolution directly

# 4. HIRES.FIX / UPSCALING STRATEGY
#    - ALWAYS enable for final outputs (especially portraits/bodies)
#    - Denoising strength: 0.1-0.3 (lower = less change, higher = more detail)
#    - Upscale by: 1.5-2.0x (start with 1.5, increase if needed)
#    - Best upscalers:
#      * 4x-UltraSharp (best detail preservation)
#      * 4x_NMKD-Superscale-SP_178000_G (excellent for faces)
#      * R-ESRGAN 4x+ (good general purpose)
#      * Latent (fastest, less quality)
#    - Two-pass approach: Generate at 768x1024, upscale to 1536x2048

# 5. PROMPT ENGINEERING
#    - Use quality tags: "masterpiece, best quality, highly detailed, 8k, uhd"
#    - Be specific: "portrait of a woman with brown hair, natural lighting"
#    - Use weights: (keyword:1.2) for emphasis, [keyword] for de-emphasis
#    - Add technical terms: "photorealistic, sharp focus, professional photography"
#    - For Realistic Vision: Focus on realism terms, avoid anime/artistic terms

# 6. NEGATIVE PROMPT OPTIMIZATION
#    - Always include base negative prompt (see recommended settings)
#    - Add specific negatives based on issues:
#      * Blurry: "blurry, out of focus, soft focus"
#      * Artifacts: "jpeg artifacts, compression artifacts, pixelated"
#      * Anatomy issues: "bad anatomy, malformed, deformed"
#      * Quality: "low quality, worst quality, normal quality"
#    - Don't overdo it - too many negatives can reduce quality

# 7. FACE & DETAIL ENHANCEMENT
#    - Enable "Restore Faces" for portraits (uses CodeFormer/GFPGAN)
#    - Use ADetailer extension (automatic face/hand detail enhancement)
